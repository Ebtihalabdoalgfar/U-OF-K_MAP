# 🗺️ University of Khartoum — Central Campus Interactive Map

An interactive web map of the University of Khartoum Central Campus, built to explore and visualize important university locations through a simple and accessible interface.

## ✨ Features

- 🗺️ Interactive map using Leaflet
- 🔎 Location search
- 📍 Interactive building markers and areas
- 🏫 University faculties and facilities
- 📚 Main Library
- 📝 Main Examination Hall
- 🌳 Campus grounds
- 🧭 Interactive popups
- 🌙 Dark-themed interface
- 🌐 Arabic RTL interface

## 🛠️ Built With

- HTML
- CSS
- JavaScript
- Leaflet.js
- OpenStreetMap

## 🎯 Project Goal

The project was created as a practical application of web mapping and geospatial concepts, with the goal of making university locations easier to explore and understand through an interactive map.

## 🧭 What I Practiced

- Interactive web mapping
- Working with geographic coordinates
- Creating map markers and polygons
- Adding search functionality
- Designing an Arabic RTL interface
- Integrating Leaflet with HTML, CSS, and JavaScript
- Organizing geospatial information for visualization
